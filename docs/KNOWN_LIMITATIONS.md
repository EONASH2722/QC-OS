# Known Limitations

- This checkout is the QC integration layer, not a synced AOSP source tree.
- Product files are host validated but an Android image has not been built here.
- Cuttlefish has not been launched; there is no emulator screenshot or profile.
- QC boot art, Setup, Home, SystemUI, Glass, Motion and Control Center are not
  implemented yet; their documents define implementation boundaries.
- MORICE, its voice/TTS pipeline, privileged actions and downloadable models are
  not present or implemented.
- Brave, QC Store, Files and Maps binaries are not integrated.
- No performance, refresh-rate, battery, security-audit or physical-device claim
  has been made.
