# Device Porting

No physical target is selected; device support is therefore **awaiting device**.
Do not reuse a similar marketing name or fabricate blobs. After selection,
record codename, SoC, bootloader/unlock requirements, legitimate device tree,
applicable kernel source and redistributable vendor artifacts. Bring-up gates
boot/SELinux first, then validate display, touch, GPU, radios, telephony, GPS,
audio, camera, biometrics, sensors, USB, power, buttons and suspend/resume.
