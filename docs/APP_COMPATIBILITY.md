# Application Compatibility

QC retains ART, Binder, Package Manager, WebView infrastructure, Android
permissions and standard app intents. Compatibility is tested with real APKs
against the reference image. QC surfaces do not forcibly alter third-party app
rendering. Brave is intended as the default browser after a legally sourced,
versioned package integration exists; this repository contains no Brave assets
or binaries and does not remove WebView.
